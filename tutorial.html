01先看这个

如果只想知道「这是个什么东西、为什么值得装」，看这一节就够了。

它不是独立软件。它是一套 Skill（技能包），需要挂在一个能运行命令、能读写文件的工具上。 本文用 WorkBuddy 演示——Claude Code、Codex、Cursor 这类同样可以，流程换成对应的按钮位置就行。

你实际需要准备三样：一个能跑它的工具、一份可用的模型额度、Node.js / Python / FFmpeg 这套运行环境（安装时会自动帮你查缺什么）。

它适合谁

  • 经常剪视频的自媒体博主后期动效、配乐、字幕这些重复活儿一次性交出去
  • 想把 PPT 变成直观视频的老师把讲义丢进去，直接出成片
  • 天天要给客户出方案的销售一个说法能变成一支可发的短片

它怎么工作

输入你告诉它想讲什么（或丢一份口播稿 / 音频）
追问它先问你几个关键问题（时长、比例、风格、语言）
分镜先出一张分镜设计表给你确认——这一步别跳过，是改稿的唯一机会
生成你回一句「可以，请帮我开始制作」，它自己调工具出片
交付成片 MP4 + 分镜表 + 消耗明细
一句话预期：以前一条视频后期动效要花几天，现在同一量级大概十几分钟—— 省下来的是重复劳动，不是你的创意时间。

进阶 自定义风格 · 七块结构模板 
帮我参考这个提示词结构，参考我给的素材设计一个新的风格【记得上传你选好的图片或者视频】

## 1. 规格定尺寸
- 比例：16:9 / 9:16 / 1:1
- 帧率：30fps；时长以配音为准
- 输出：MP4（H.264），音频 AAC

## 2. 风格定长相
- 主色 3～5 个，写出色值（如 #0B1E3F）
- 背景：纯色 / 渐变 / 纹理
- 质感：扁平 / 立体光影 / 玻璃 / 纸张 / 线稿
- 字体气质：粗黑 / 圆体 / 手写 / 衬线
- 构图特点：留白多少、元素密度、居中还是偏置

## 3. 节奏定时间
- 每个镜头 3～5 秒
- 一个画面最多同时展示 5～7 个信息块

## 4. 画面定动作
- 主角元素怎么动：从哪来、到哪去、多长时间
- 口播里的数字和关键词必须出现在画面上
- 转场方式

## 5. 音乐定情绪
- 背景音乐风格和 BPM
- 音效：什么时候用什么音
- 背景音乐音量压到人声的 15%～25%，结尾 1 秒淡出

## 6. 工具定实现
- 用什么工具和库来做
- 动画怎么写（spring / interpolate）

## 7. 交付定检查
- 文字有没有溢出或被截断
- 配色是不是所有镜头都统一
- 按交付前检查清单逐项确认

它会怎么处理你的素材

它不是随便给你改改配色，而是先把你这张图的视觉机制拆开——哪条线是强调色、字重压到多少、底色冷到什么程度——再列一张「新旧差异」表告诉你它改了什么，最后按七块结构写成一份完整的模板文件。

这份文件就是你以后说的「我自己的风格」。想固化下来，跟它说：

06避坑清单

四个最容易翻车的地方，都是实测踩出来的。

  • AI 偶尔会发挥，数字不一定对年代、术语、数字它写出来的不保证正确。要对外发布的东西，关键处自己再核一遍。
  • 第一次没跑通，多半是环境没配齐不同电脑、不同工具版本效果会有差别。别怀疑自己，回头看报错就行——Node.js / Python / FFmpeg 缺哪个它会提示。
  • 用在线配音，文稿会送到语音服务那边没公开的内容先别直接贴。图片、字体、音乐和音效商用之前也请自己确认授权，公版图记得把署名留下。
  • 分镜表是改稿的唯一机会生成之后改一个数字都要重跑。确认分镜那一步多花两分钟，比出片后返工划算。
关于公测版：它不是装完就什么都不用管的独立软件。你还需要一个能运行它的工具、一份可用的模型额度，以及 Node.js、Python、FFmpeg 等运行环境。 装完遇到问题，把报错和复现步骤发给 WorkBuddy，它会帮你继续改。
